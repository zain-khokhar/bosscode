# Page-by-Page Landing Playbooks Reference

## 1. Home Page (`/`)
- **3-Second Landing Hook:** H1 `"From Paper To Digital. Made Simple."` + 1-line subtitle + Interactive **Register vs. Digital App** visual preview on the right (showing actual `Rs` sales, stock alerts, and WhatsApp reminders instead of code syntax).
- **Visual Flow:**
  1. **Hero:** Visual Paper-to-Digital Switcher + `Free Check-up` & `See Solutions` CTAs.
  2. **Stats Bar:** 4 big trust numbers (`24h` Reply, `100%` Yours, `7d` Preview, `Free` First Chat).
  3. **What We Do (`Services`):** 6 clickable cards linking directly to `/solutions/[slug]`, each with a 1-line description (max 10 words).
  4. **Problems We Fix (`CapabilityFan`):** Interactive problem-to-solution switcher where clicking any problem tab or card highlights the exact fix and links to it.
  5. **Real Examples (`Portfolio`):** 3 live interactive `<ProductMock compact />` cards for Retail Shop (`ShopLedger`), Clinic (`ClinicFlow`), and Wholesaler (`BillBot`) linking directly to their solution pages.
  6. **Our Promise (`QuantumCore`):** High-contrast dark navy section with 4 visual promise badges.
  7. **How It Works (`ProcessTimeline`):** 4 simple steps (`Free Chat` → `See Design` → `We Build` → `We Support`), max 8 words per step.
  8. **Common Questions (`Testimonials/FAQ`):** Stationary, scannable 2-column FAQ accordion/grid (no moving marquee).
  9. **CTA Banner:** Direct WhatsApp + Free Check-up buttons.

## 2. Solutions Hub (`/solutions`)
- **3-Second Landing Hook:** `"Pick Your Problem. See the Fix."` + Interactive category filter chips + 5 live `<ProductMock compact />` solution cards.
- **Rule:** Visitors immediately see live mini-dashboards for every product without reading long descriptions.

## 3. Solution Detail (`/solutions/[slug]`)
- **3-Second Landing Hook:** Product Name + 1-line outcome tagline + `"Who it's for"` industry pills + Auto-cycling interactive `<ProductMock />` with 3 live tabs (`Today`, `Stock/Records`, `Dues/Reminders`).
- **Visual Flow:**
  1. **Product Hero:** Left summary + Right interactive `<ProductMock />`.
  2. **Visual Before vs. After:** Strike-through red/grey `"On Paper Today"` vs. Navy/Blue `"With [Product]"`, max 4–5 words per bullet.
  3. **6 Micro-Feature Tiles:** Icon + 2-word title + 6–8 word benefit.
  4. **3-Step Setup:** `1. Setup` → `2. Daily Use` → `3. Full Control`.
  5. **3 Quick FAQs + WhatsApp/Contact CTA.**

## 4. About Page (`/about`)
- **3-Second Landing Hook:** `"Software Built Around Your Business."` + Animated `Paper → Digital` visual bridge.
- **Visual Flow:** 4 core belief micro-cards + 4-step work promise + Free Chat CTA.

## 5. Contact Page (`/contact`)
- **3-Second Landing Hook:** `"Let's Have a Free Chat."` + 1-tap problem selector pills + 30-second form that opens WhatsApp directly (with email fallback).

## 6. Policies Page (`/policies`)
- **3-Second Landing Hook:** `"Simple Rules. Plain Words."` + 5 visual summary cards with 1-sentence rules, with expandable Q&As for details.
